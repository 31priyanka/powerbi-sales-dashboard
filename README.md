📊 Power BI Sales Dashboard

An interactive Sales Performance Dashboard built using Power BI to analyze e-commerce sales data and generate actionable business insights.

🚀 Features

KPI tracking: Total Sales, Total Orders, Profit, and Profit Margin

Time-based analysis: Monthly trends and Year-to-Date (YTD) performance

Category and region-wise sales analysis

Identification of top-performing products and customers

Interactive slicers for dynamic and user-driven exploration

🛠 Tools & Technologies

Power BI

DAX (Data Analysis Expressions)

Power Query (Data Cleaning & Transformation)

Data Modeling (Star Schema)

📐 Data Modeling

Implemented a star schema for efficient data organization

Fact Table: Orders

Dimension Tables: Customers, Products

Established relationships to optimize performance and enable accurate analysis

📈 Key Insights

Identified top revenue-generating categories and regions

Highlighted underperforming segments with low profitability

Observed that a small percentage of customers contribute significantly to total revenue

Detected trends in sales performance across different time periods
