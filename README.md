# 📊 Power BI Sales Dashboard

## 📌 Project Overview
This project presents an interactive **Sales Performance Dashboard** built using Power BI to analyze e-commerce sales data and generate actionable business insights.

The dashboard transforms raw transactional data into meaningful visual insights, helping stakeholders understand sales trends, customer behavior, and overall business performance.

---

## 🎯 Business Objective
The primary objective of this project is to:
- Analyze overall sales, orders, and profit trends  
- Identify top-performing products, categories, and regions  
- Understand customer purchasing behavior  
- Highlight underperforming areas for improvement  
- Enable data-driven decision-making  

---

## 🚀 Features
- KPI tracking: Total Sales, Total Orders, Profit, and Profit Margin  
- Time-based analysis: Monthly trends and Year-to-Date (YTD) performance  
- Category and region-wise sales analysis  
- Identification of top-performing products and customers  
- Interactive slicers for dynamic and user-driven exploration  

---

## 🛠 Tools & Technologies
- Power BI  
- DAX (Data Analysis Expressions)  
- Power Query (Data Cleaning & Transformation)  
- Data Modeling (Star Schema)  

---

## 📐 Data Modeling
- Implemented a **Star Schema** for efficient data organization  
- **Fact Table:** Orders  
- **Dimension Tables:** Customers, Products  
- Established relationships to ensure optimized performance and accurate analysis  

---

## 📈 Key Insights
- Top-performing categories and regions contribute significantly to overall revenue  
- Some segments show low profitability despite high sales volume  
- A small percentage of customers drive a major portion of total sales  
- Sales trends vary across different time periods, indicating seasonality
